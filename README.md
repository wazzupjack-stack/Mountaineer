# Mountaineer

A parimutuel prediction-market demo themed around mountain ascents. Two static, dependency-free HTML pages — no build step, no backend, no server required.

> **Demo build.** All balances are play tokens (TKN) with no monetary value.

## Pages

### `index.html` — Peak Prediction Markets

The main page. Six real mountains (Everest, K2, Aconcagua, Denali, Kilimanjaro, Mont Blanc), each running two distinct kinds of market side by side:

**Simulated bracket markets** (`#markets`) — a parimutuel betting game skinned as a climb. Each round, a mountain "climbs" from a base-camp altitude toward its real summit height on a live multiplier; players back a bracket (Base Camp / Camp II / High Camp / Summit) before the round locks, the pool's share per bracket sets the implied odds, and the winning bracket splits the pot pro-rata minus a 5% rake. The event itself (where the "peak" lands) is generated by the page — this is a crash-style gambling game with real prediction-market plumbing (crowd-set odds, pooled payout), not a genuine forecast of anything.

**Real markets** (`#real-markets`) — a second, slower, and genuinely real market. Each mountain's live wind speed and temperature are fetched from [Open-Meteo](https://open-meteo.com) (free, no API key, elevation-corrected for that summit's real altitude). Those two raw numbers are shown as-is (so players can weigh them directly), and are also fed into a disclosed formula — calm (≤20 km/h) and mild (≥-25°C) conditions allow the full real summit; conditions scale down linearly to base camp by 60 km/h wind or -45°C, whichever binds hardest — that estimates a **climbable altitude**, in meters, on the same Base Camp / Camp II / High Camp / Summit ladder as the game above it. Players bet on which of those brackets live conditions will allow ~6 hours out; odds are seeded from that estimate's own uncertainty spread, and the round resolves against a real re-fetch once that real timestamp actually passes — on a real clock, not an accelerated one. Nobody on the page controls the outcome. (The pool of other participants is still simulated, same as the rest of the site — there's no backend or multiplayer here — but the weather inputs, the climbable-altitude formula, and the resolution are all real and independently checkable.)

Also included: a portfolio/session summary, a simulated leaderboard, a simulated global activity feed, and a dark/light theme toggle (persisted via `localStorage`).

### `mountaineer.html` — single-ascent crash game

A focused, single-mountain version of the climbing mechanic — a classic crash game (stake, watch the multiplier climb, cash out before it peaks or lose the stake). Linked from each mountain card on `index.html` ("▲ PLAY LIVE ASCENT") via `mountaineer.html?mountain=<id>`, which loads that specific mountain's real name and elevation. Also has its own dark/light toggle and a link back to `index.html`.

## Running it

No install, no server — just open either file in a browser:

```
open index.html
```

`index.html`'s Real Markets section makes live network requests to `api.open-meteo.com`; everything else on both pages runs entirely client-side.

## Notes on the "real" in Real Markets

- **Real**: the wind speed and temperature (live, from Open-Meteo, at each mountain's real coordinates/elevation), the resolution timestamp, and the settlement (re-fetched and checked against actual conditions once real time passes it).
- **Disclosed, not raw**: the "climbable altitude" bracketed by the market is a formula applied to those real inputs, not a directly-measured fact — the exact thresholds are shown in the UI (hover any "CLIMBABLE ALTITUDE" label) rather than hidden, but it's still a modelling choice, not a certified meteorological product.
- **Simulated**: the wallet balance, the other participants' pool contributions, the leaderboard, and the activity feed — this is a static page with no backend, so there's no real multiplayer crowd.
