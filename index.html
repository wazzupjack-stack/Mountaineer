HOW VERTICAL METRES WORK
Every stake banks metres for the altitude it actually reached — a fall still counts the climb. Dangerous peaks pay a higher weight, so K2 advances you 1.8× as fast as Kilimanjaro for the same stake and altitude.
VM = stake × (metres above base ÷ 100) × peak weight
Camps decay. Hold a camp by banking 30% of its requirement each month, or drop one camp. Rakeback boosts stack on top of the peak's own offering but are capped so effective RTP never passes 99.5%.

Demo build — thresholds are tuned short so the ladder is visible in a single session. Progress is not saved between reloads.
